      Integration Center
      API Connections
      Configure data sources for performance, activity, forecasting, conversation intelligence, and reporting. This UI is a front-end administration layer; production use should route credentials through a secure backend or secrets manager.
      Ready

      Generic API

      Connect any REST or GraphQL endpoint for custom CRM, data warehouse, enrichment, or internal sales operations feeds.

      • Supports API key, bearer token, OAuth, or custom headers.
      • Use for pipeline, quota, activity, territory, or custom KPI data.
      • Recommended for internal systems and prototypes.
      Ready

      Salesforce

      Primary CRM source for opportunities, accounts, ARR, stages, close dates, forecast category, owners, and activity history.

      • Objects: Opportunity, Account, User, Task, Event, ForecastingItem.
      • Maps to bookings, pipeline, stage, category, close date, and owner.
      • Best source for quota and opportunity inspection workflows.
      Ready

      Gong

      Conversation intelligence source for call quality, executive engagement, deal risk, next steps, and customer sentiment.

      • Use to validate Director+ engagement and opportunity health.
      • Extract next steps, competitors, objections, and MEDDICC signals.
      • Supports coaching evidence in Recommendations.
      Ready

      Tableau

      Reporting and dashboard source for curated performance datasets, quota tables, historical trends, and executive views.

      • Use published data sources or dashboard exports.
      • Good for team benchmarks, territory views, and historical attainment.
      • Can power management-ready reporting summaries.
      Optional

      Snowflake / BigQuery

      Data warehouse integration for blended sales, finance, product, marketing, and customer success datasets.

      • Best for normalized, governed reporting models.
      • Use for historical trend models and benchmark calculations.
      • Supports large-scale analytics beyond CRM-only views.
      Optional

      Outreach / Salesloft

      Sales engagement source for email, call, sequence, and prospecting activity quality.

      • Maps to emails, calls, LinkedIn/social touches, and cadence outcomes.
      • Useful for activity effectiveness and weekly KPI sprint coaching.
      • Pairs well with Salesforce opportunity creation.
      Optional

      Clari

      Forecasting source for confidence scores, forecast categories, commit/upside views, and deal inspection workflows.

      • Maps directly to forecast confidence and probability to achieve quota.
      • Useful for Category, Stage, Clari confidence scoring.
      • Improves projected attainment accuracy.
      Optional

      Workday / HRIS

      People and organizational hierarchy source for manager, region, team, role, tenure, and territory metadata.

      • Useful for team/manager mapping and onboarding cohorts.
      • Supports performance segmentation by tenure or role.
      • Helps normalize rep-to-rep comparisons.
      Optional

      CSV / Google Sheets

      Lightweight import path for manual uploads, prototypes, weekly exports, or spreadsheet-managed KPI data.

      • Fastest path for early testing and manager-owned data.
      • Useful for quota sheets, custom KPIs, and manual pipeline exports.
      • Can be replaced later with automated API feeds.
